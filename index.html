关于我

我从 2014 年开始做 iOS 开发，长期深耕 Swift、UICollectionView 布局与动画， 对移动端体验和工程细节有近乎偏执的追求。

随着 AI 浪潮到来，我把重心转向全栈 + AI 系统开发， 从移动端手艺延伸到后端服务、LLM 路由、自动化工作流和智能 Agent 架构。

当前聚焦 AI Agent Frameworks、Multi-Provider LLM Routing、Automated Workflows。 理念很简单：Ship fast, automate everything, let agents handle the boring stuff。

目前在杭州，组织：老司机技术。
