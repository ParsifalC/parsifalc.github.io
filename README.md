# Parsifal · 第一人称 3D 矩阵展馆

这是无框架的原生静态 ESM 站点。浏览器从 `index.html` 加载 `src/main.js`，样式位于 `src/styles.css`，Three.js 使用本地 `vendor/` 资源。开发和构建脚本仅使用 Node.js 标准库；构建保持文件结构，不做打包、转译或压缩。

## 本地开发

安装可运行原生 ESM 和 Node 标准库文件 API 的 Node.js，然后在仓库根目录运行：

```sh
npm run dev
# 指定端口（命令行优先于环境变量）
npm run dev -- --port 4300
# 也可通过环境变量设置
PORT=4300 npm run dev
```

也可以直接运行 `node scripts/dev-server.mjs`。默认地址为 `http://127.0.0.1:4173/`，启动时会打印实际 URL；服务只监听本机。支持 GET / HEAD、常见静态资源 MIME 和目录的 `index.html`。缺失资源返回 404，不回退到首页；路径穿越、隐藏文件、`.git`、`.env`、`node_modules` 及指向站点外部的符号链接都会被阻止。

请通过 HTTP 地址预览；不要直接双击 HTML 使用 `file://` 打开 ESM 站点。修改后手动刷新浏览器。

## 构建与部署

```sh
npm run build
# 等价于
node scripts/build.mjs
```

构建仅清理仓库内的 `dist/`，再复制以下已存在的条目；缺失项会列出并跳过，不生成占位文件：

```text
index.html  src/  vendor/  assets/  docs/
favicon.svg  site.webmanifest  CNAME  .nojekyll  robots.txt  sitemap.xml
```

依赖目录、测试、测试产物、隐藏配置与已知研究采集目录不会进入产物；输入符号链接及符号链接形式的 `dist` 会使构建失败。发布前仍需确认公开素材目录只包含适合公开的内容。

GitHub Pages 可采用以下任一方式，均需自行配置发布来源：

- **仓库根目录直接发布**：选择相应分支的根目录作为 Pages 来源，原生 ESM 文件即可直接提供给浏览器；保留 `.nojekyll`。
- **发布构建产物**：运行构建后，将整个 `dist/` 作为 Pages artifact 交给发布工作流，或交给其他静态托管服务。Pages 的分支目录选择不会直接识别 `/dist`，产物发布需另行配置。

本仓库的开发、构建命令不会提交、推送或部署。使用现有自定义域名时保留 `CNAME`；更换域名或使用项目子路径时，发布前同步检查资源路径、canonical、manifest、robots 和 sitemap。

## 内容与交互

项目资料集中维护在 `src/content.js`；按该文件现有字段修改产品简介、技术标签、展示层级与公开入口。私有项目只展示经确认的产品摘要，不放私有仓库链接、内部网络地址、凭据、账号配置或采集原文。

桌面端通过 **WASD** 移动、**拖拽**改变视角、**点击**展项查看详情；**地图**用于定位展区，**目录**用于直接浏览内容。音频默认关闭，由访客主动开启。

3D 模式需要支持 WebGL2 的浏览器和可用的图形上下文。无 WebGL2、3D 初始化失败或不适合漫游时，应能通过目录访问内容。低动态模式应遵循系统的“减少动态效果”偏好，并降低持续动画和镜头运动；目录也是避免漫游的入口。

## 本地验收步骤

1. 运行 `node --check scripts/dev-server.mjs` 和 `node --check scripts/build.mjs`，启动开发服务，确认终端地址可访问。
2. 检查浏览器控制台和 Network：入口、CSS、本地 Three.js、模型及音频资源按实际使用正常加载；不存在资源返回 404，不能返回首页 HTML。检查自定义端口与 HEAD 请求。
3. 检查 WASD、拖拽、展项点击、地图、目录与返回路径；打开详情或输入控件时，确认移动控制不会干扰操作。检查窄屏和触摸使用。
4. 首次进入确认没有音频自动播放；检查主动开启、关闭及离开交互后的状态。
5. 在浏览器开发工具模拟 `prefers-reduced-motion: reduce`，检查低动态表现；模拟 WebGL2 不可用，确认目录和项目详情仍可使用。
6. 运行构建，确认 `dist/` 只包含公开站点文件，并检查私有项目仅有产品摘要。依赖或素材尚未齐备时，不把“构建完成”视为完整页面验收。

这些是交付验收步骤，不表示所有浏览器交互已由脚本自动测试。
