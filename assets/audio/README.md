# Construct · 无底噪场景音乐

五首旋律均为本项目创作。入口曲目使用本机系统钟琴、竖琴音源离线渲染；不包含现成歌曲，也不分发原始音源库。其余四首为程序合成音乐。当前版本已移除全部随机噪声、磁带沙沙声、合成雨声、雨滴和机器环境声；保留旋律、和声与音乐低音。

| 文件前缀 | 场景 |
| --- | --- |
| 01-hidden-celesta-legato | 入口：隐秘星图连贯版，64 秒钟琴与竖琴循环 |
| 02-rain-on-concrete | 自由漫游（保留原曲名，已无雨声） |
| 03-signal-drift | 地图与前往展台 |
| 04-archive-room | 作品索引与详情 |
| 05-human-node | 关于与联系 |

入口 MP3 为 40 秒试听，其余为 24 秒试听（44.1 kHz / 入口 192 kbps、其余 160 kbps，首尾淡入淡出）；同名前缀的 -loop.wav 为完整乐句循环（24 kHz / 16-bit / 立体声）。WAV 避免有损压缩首尾填充，音乐尾音在循环边界连续。

src/soundtrack.js 按需加载循环，2 秒交叉淡入淡出，已加载曲目保持播放相位；默认开启；自动播放受限时在首次交互后启动，可随时关闭。脚本 scripts/render-soundtracks.py 可复现素材，使用 numpy 与 ffmpeg；入口由 scripts/render-hidden-celesta.py 调用 macOS Swift 乐器渲染器制作，响度约 −23 LUFS，其余约 −20 LUFS，播放时再适度降低主音量。

入口隐秘星图连贯版延长主旋律音符并使尾音轻微重叠，以流动竖琴衔接乐句；声部分开，避免同音符收尾互相截断。循环包含上一轮尾音并在同乐句位置平滑匹配，无持续低频铺底或独立噪声层。旧版 01-green-terminal 与 01-quiet-threshold 文件仅保留旧链接兼容，当前站点不再引用。
